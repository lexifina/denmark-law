# Lov om Danmarks tiltrædelse af De europæiske Fællesskaber (Tiltrædelsesloven) Bilag 1 til loven: Traktat om oprettelse af Det europæiske økonomiske Fællesskab (EØF-traktaten), herunder konventionen vedrørende fælles institutioner for De europæiske Fællesskaber Bilag til EØF-traktaten II. Protokoller Protokol vedrørende den ordning, der skal finde anvendelse på varer, som henhører under Det Europæiske Kul- og Stålfællesskab med hensyn til Algeriet og Den Franske Republiks oversøiske departementer (* 1)
