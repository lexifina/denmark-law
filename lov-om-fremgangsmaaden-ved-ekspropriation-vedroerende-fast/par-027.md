Stk. 2. Ministeren for offentlige arbejder kan i enkelte tilfælde fravige de i denne lov fastsatte regler om bekendtgørelse af møder, offentliggørelse af planer m.v., såfremt hensynet til statens sikkerhed kræver det.

Stk. 3. Ministeren for offentlige arbejder kan fastsætte nærmere regler om ekspropriationsmyndighedernes forretningsgang.

Stk. 4. Landbrugsministeren og justitsministeren kan fastsætte nærmere regler om fremgangsmåden ved matrikulære og tinglysningsmæssige berigtigelser, der foranlediges af ekspropriationer.
